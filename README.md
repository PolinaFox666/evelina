# Эвелина — премиальный лендинг

Полностью статический русскоязычный сайт для GitHub Pages. Не требует сборки или платного хостинга.

## Структура

- `index.html` — все тексты и разметка, включая спрятанную улику в комментарии `<head>`.
- `styles.css` — оформление и мобильная адаптация.
- `site.js` — ненавязчивое появление разделов при прокрутке.
- `assets/obsidian-orb.webp` — авторская абстрактная иллюстрация хрустального шара.
- `assets/favicon.svg` — иконка вкладки.
- `audio/` — положить MP3-файл `olivia-call.mp3`.

## Опубликовать в GitHub Pages

1. Распакуйте архив и загрузите **содержимое папки `evelina-site`** в корень репозитория GitHub (файл `index.html` должен лежать в корне).
2. `Settings` → `Pages` → `Build and deployment`: `Deploy from a branch` → `main` → `/ (root)` → `Save`.
3. Откройте ссылку Pages из настроек. Если URL репозитория `https://user.github.io/evelina/`, подсказка с относительным путём `audio/olivia-call.mp3` будет работать именно в этом подкаталоге.

## Добавить аудиозапись

Создайте или используйте папку `audio` в корне сайта и загрузите запись как **`olivia-call.mp3`**. Проверьте, что она открывается по адресу `https://ВАШ-ДОМЕН/audio/olivia-call.mp3` (для проектного GitHub Pages вместо домена будет полный URL сайта с названием репозитория).

**Не удаляйте комментарий в начале `index.html`:** он содержит подсказку «АУДИОЗАПИСЬ № 04», которую игроки увидят в исходном коде страницы (`Ctrl+U` или `Cmd+Option+U` в некоторых браузерах).

## Добавить Telegram

В конце `index.html` в разделе `<section class="telegram">` уже находится закомментированный пример тега `<a>` с адресом `https://t.me/ИМЯ_КАНАЛА`.

1. Раскомментируйте тег `<a class="telegram-link" ...>`.
2. Замените `ИМЯ_КАНАЛА` на точное имя канала.
3. Удалите следующий `<span class="telegram-link telegram-disabled">`.

На странице появится рабочая ссылка без изменения оформления.

## Дизайн

Дизайн намеренно лаконичный: тёмные текстуры, приглушённый металлический оттенок, единая типографика Forum, объёмная колода с картой Q♠. Фотографии гадалки не используются. При отсутствии интернета включается системный шрифт с засечками. Сайт доступен на телефонах и учитывает настройку «уменьшение движения».
