# Эвелина + фестиваль «КОНТУР»

Два готовых статических сайта внутри **одного GitHub Pages-репозитория**. Никакой сборки или серверных программ не нужно.

## Страницы

- `index.html` — **сайт Эвелины**. Премиальный тёмный дизайн исходного сайта сохранён. В блоке фильма «Предсказано» появилась кнопка **«ПОСМОТРЕТЬ САЙТ ФЕСТИВАЛЯ»**: она открывает `festival.html` в новой вкладке.
- `festival.html` — **отдельная страница фестиваля «КОНТУР '26»** в самостоятельном современном оформлении; 10 других фильмов с собственными постерами и «Предсказано» (11 фильмов всего).
- `festival.css` — оформление и адаптивная мобильная версия страницы фестиваля.
- `styles.css`, `site.js` — оформление и анимация сайта Эвелины.
- `assets/posters/` — 10 оригинальных локальных постеров для вымышленных фильмов.
- `assets/obsidian-orb.webp` — оригинальное изображение шара, используется на обоих сайтах.
- `audio/` — место для аудиозаписи `olivia-call.mp3`.

## Как разместить на GitHub Pages

Если сайт Эвелины уже опубликован, **загрузи файлы из папки `evelina-site` в тот же репозиторий**, заменив `index.html` и `styles.css` и добавив новые `festival.html`, `festival.css`, `assets/posters/`. Сохрани имеющиеся файлы, особенно папку `audio/` с записью и любые изменения, сделанные на сайте вручную.

Если публикуешь впервые:
1. Загрузи **содержимое папки `evelina-site`** в корень репозитория. В корне должны находиться **оба** файла `index.html` и `festival.html`.
2. В GitHub открой `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` → `/ (root)` → `Save`.
3. Страница Эвелины будет доступна по адресу проекта GitHub Pages, а фестиваль — по этому же адресу с окончанием `/festival.html`.

Все ссылки относительные: работают и на адресе `username.github.io`, и внутри подпапки проекта `username.github.io/имя-репозитория/`.

## Улика с аудиозаписью

**Не удаляй HTML-комментарий в начале `index.html`!** Там полностью сохранилась исходная подсказка «АУДИОЗАПИСЬ № 04» и путь `audio/olivia-call.mp3`. В конце `index.html` остался скрытый элемент `template` с той же ссылкой.

Чтобы запись проигрывалась, файл надо положить в папку `audio/` под именем `olivia-call.mp3` (в архив не включён). Игроки увидят подсказку, открыв исходный код страницы.

## Нора и «Предсказано»

На странице фестиваля фильм «Предсказано» находится **в общей программе под номером 04** со статусом **«УЧАСТИЕ ПОД ВОПРОСОМ»**, режиссёр — **Нора Вейл**, финальная копия ожидается **до 31 октября, 12:00**. Фамилия **«Вейл»** была придумана для макета, так как ранее была известна только Нора.

Если понадобится изменить её, найди `Нора Вейл` в файле `festival.html` и замени на нужное полное имя.
